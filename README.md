In Pixel Run, the player controls a character running on an 
endless obstacle course, inspired by the popular T-Rex Game. The player’s goal 
is to avoid obstacles that appear in random locations and collect coins scattered 
along the way. The game allows players to spend collected coins on various 
items, such as character skins and new backgrounds, offering personaliztion 
options to enhance gameplay. As the game progresses, obstacles become 
increasingly difficult to avoid, and the running speed gradually increases, raising 
the challenge level. The player may encounter various power-ups that appear 
which they can pick up, which will help player in various ways
